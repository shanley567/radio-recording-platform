# Troubleshooting S3 Uploads

## Verify Bucket

```bash
aws s3 ls
```

---

## Verify Uploads

```bash
aws s3 ls s3://jsp-radio-recordings-bucket-2026-demo --recursive
```

---

## Expected Structure

```text
station-001/YYYY/MM/DD/HH/file.json
station-002/YYYY/MM/DD/HH/file.json
station-003/YYYY/MM/DD/HH/file.json
```

---

## Validation

Uploads should appear continuously while the generator pod is running.
